# 阶段 02：架构设计

## 功能简介

将阶段 01 的创意纲要展开为结构骨架。分两轮执行：第一轮定终点、切卷、识别角色功能需求（不与具体人物绑定）；第二轮在人物工坊完成后用角色动机精化为章级大纲。

## 触发条件

用户说"大纲""卷结构""节奏""规划""分卷"时加载本手册。

**两轮设计**：本阶段分两轮执行——
- **第一轮**：01 之后立即执行，产出粗略骨架 + 角色功能需求
- **第二轮**：03（人物工坊）完成后回访，用角色动机精化骨架

## 前置条件

- 第一轮：`brief.md` 已建立（核心冲突、情感引擎已定义）
- 第二轮：`tracking/characters/` 已建立（L4 主角全卡填满，L3 关键配角已设计）

---

## 第一轮：粗略骨架

### 目标

不写细。只定三件事：**终点在哪、怎么分段、需要什么人**。

### 流程

#### Step 1: 确认输入

读取 `brief.md`。确认核心冲突和情感引擎。不明确则先回阶段 01。

#### Step 2: 定终点

故事结束时，主角处于什么状态？读者感受到什么情绪？

例："露露莉亚真正理解了王的意义，不再依赖日记也能做决定。读者感受：一个女孩从被命运压垮到主动扛起命运。"

#### Step 3: 切分卷结构

每卷二要素：

| 要素 | 含义 |
|------|------|
| **卷核心功能** | 引入/建立/深化/转折/收束 — 这一卷在故事中起什么作用？ |
| **卷末状态** | 主角在这个阶段结束时，处境和心态有什么变化？ |

首卷 3 章内必须出核心前提（让读者知道"这个故事讲什么"）。

#### Step 4: 识别角色功能需求

基于核心冲突和卷结构，列出**故事需要什么功能的人**——不设计具体人物，只问功能：

| 功能类型 | 说明 | 示例 |
|----------|------|------|
| 导师/镜子 | 帮助主角成长或映照主角困境 | "需要一个引导主角认识世界的角色" |
| 催化/对抗 | 推动情节或制造冲突 | "需要一个外部压力源，迫使主角学做王" |
| 伙伴/见证 | 陪伴主角、提供情感支撑 | "需要一个能与主角吐槽、并肩的同伴" |
| 变量/代价 | 引入不确定性或展示选择的后果 | "需要一个人物的命运展示'如果不改变会怎样'" |
| 世界展示 | 展示世界观的某个侧面 | "底层区需要一个角色，让主角看到真实民生" |

**禁止在此阶段设计具体人物**——不命名、不定性格、不定弧线。只产出功能需求列表，交给阶段 03。

#### Step 5: 写入骨架版

写入 `outline.md`（使用 `templates/outline.md` 模版），标注骨架版：
- 终点状态
- 卷结构（含核心功能和卷末状态）
- 角色功能需求列表（标注"待 03 设计"）

**骨架版完成标准**：
- [ ] 终点已定
- [ ] 卷已切分（各自有核心功能 + 卷末状态）
- [ ] 首卷前 3 章能出核心前提
- [ ] 角色功能需求列表完整（至少含：导师/对抗/伙伴三种功能）
- [ ] outline.md（骨架版）已写入
- [ ] → 停在这里，进入阶段 03：人物工坊

## 第二轮：精化

### 触发

阶段 03 完成后回访。用户说"精化大纲""细化到章""用角色填大纲"时也可触发。

### 前置检查

- [ ] L4 主角全卡已填满（Wound→Lie→Want→Need 完整，弧线已定）
- [ ] L3 关键配角已设计（声线卡、弧线简述）
- [ ] L2 有趣角色已按需完成

### 流程

#### Step 1: 用角色动机填充骨架

逐卷重审第一轮的粗略描述。每个情节点追问：**是哪个角色的什么动机驱动的？**

```
骨架版: "第二卷中期，主角面临一次重大选择"
精化版: "露露莉亚的 Lie（我不配当王）被宫廷质疑事件触发，
        她面临选择：诉诸日记（依赖外部）还是自己判断（开始成长）。
        瑟拉芬的 Want（保护露露莉亚）与 Need（信任她的判断）
        在此产生张力——他想替她挡，但真正的成长需要她自己去。"
```

#### Step 2: 细化到篇章

至少前十章具体到场景摘要。之后每章标注核心功能（主角弧线节点/情节推进/人物深化/世界展示）和关键登场人物。

#### Step 3: 角色弧线与情节对准

检查每个 L4/L3 角色的弧线节点是否与情节对齐：

- 催化事件 → 哪一章发生？
- 中点觉醒 → 哪个情节触发？
- 最低谷 → 哪一章？
- 终点 → 哪一章？

弧线节点未嵌入情节的 → 补入。情节没有推动弧线的 → 调整。

#### Step 4: 设计节奏

上升期 → 高潮 → 回落 → 过渡。最长连续上升 ≤ 5 章，最短回落 ≥ 1 章。

#### Step 5: 设计衔接

直接接续 + 伏笔回收 + 人物复出 + 意象呼应。每卷至少埋 2 条伏笔、收 1 条。标注信息差（某角色知道某角色不知道的事）。

#### Step 6: 精化 outline.md

基于以上内容，将 `outline.md` 从骨架版更新为精化版。

## 输出物

| 交付物 | 模板 | 路径 | 用途 |
|--------|------|------|------|
| outline.md（骨架版） | — | workspace/novels/{name}/outline.md | 第一轮产出：终点、卷结构、角色功能需求 |
| outline.md（精化版） | — | workspace/novels/{name}/outline.md | 第二轮产出：在骨架版上精化，含章级大纲、弧线节点、伏笔衔接 |

## 完成标准（精化版）

- [ ] 终点 + 卷结构不变（骨架版已定）
- [ ] 每个卷末状态的"谁做了什么选择导致这个状态"已写清
- [ ] L4/L3 弧线节点已嵌入章节
- [ ] 前十章有场景摘要
- [ ] 节奏检查通过（高潮后有回落，连续上升 ≤ 5 章）
- [ ] 每卷伏笔/回收 ≥ 2/1
- [ ] outline.md 已更新为精化版
- [ ] → 进入阶段 04：世界构建

## 常见错误

1. **第一轮就写细。** 骨架还没定就写场景摘要 → 写了又改。先粗后细。
2. **角色功能需求跳步。** 第一轮没说"需要什么人"就直接进 03 造人 → 03 盲造。
3. **第二轮用情节推人物而非人物推情节。** 精化版大纲应该是"瑟拉芬因为某原因做出某选择"而非"发生某事件"。
4. **弧线节点与情节脱节。** 弧线写了"中点觉醒"但大纲里没有对应的章节和事件。
5. **大纲当铁律。** 创意超大纲时，先确认不破坏核心冲突，再调整大纲。
