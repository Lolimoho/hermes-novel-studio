# 阶段 03：人物工坊

## 功能简介

将阶段 02 的角色功能需求落地为具体人物。采用四层角色体系（L4主角→L3完整性→L2有趣性→L1功能性），按层级裁剪填写角色卡。不只在初始设计阶段执行——写作中、审稿后、追踪时均可回访触发本手册。

> 综合参考：Lajos Egri 《The Art of Dramatic Writing》三维角色理论、Robert McKee 《Story》、K.M. Weiland 角色弧线方法论。融入 [novel-writer-skills](https://github.com/wordflowlab/novel-writer-skills)「角色弧线+关系追踪」系统、[ClawHub novel-writing](https://clawhub.ai/zton100/novel-writing)「角色声线卡」机制。

## 触发条件

用户说"新角色""角色设计""人物卡""角色弧线""反派设计""人物关系"时加载本手册。也可在以下时机自动触发：阶段 05 写作中新角色意外登场、阶段 06 审稿后发现辨识度不足、阶段 08 追踪时发现角色需升级层级。

## 前置条件

- 阶段 01 的 `brief.md` 已建立
- 阶段 02 第一轮的**角色功能需求列表**已建立（知道故事需要什么功能的人）

## 二、操作流程

## 角色层级与填写深度

| 层级 | 定义 | 判定标准 | 推荐填写深度 | 数量 | 笔墨占比 |
|------|------|----------|-------------|------|---------|
| **L4 主角级** | 故事围绕他展开，有独立弧线 | POV角色 / 核心冲突推动者 / 结尾有成长 | **全卡填满**（所有字段） | 1-3 | 60-80% |
| **L3 完整性** | 完整人格，有独立动机，弧线可简 | 对主角有持续影响 / 有独立立场 / ≥3章登场 | **核心必填**（基础+性格内核+弧线简述+声线卡+外在标记+关系+触发器） | 5-10 | 15-30% |
| **L2 有趣性** | 有辨识度但无独立弧线，功能明确 | ≥2个记忆点 / 每次登场风格一致 / 带动情节但不主导 | **辨识度必填**（基础+三词+声线3项+外在标记+功能） | 10-30 | 5-10% |
| **L1 功能性** | 故事工具人，一个功能用完即走 | ≤2次登场 / 没有独立情节线 / 不要求辨识度 | **最小必填**（基础+功能+登场记录） | 不限 | <5% |

**L4 → L3 → L2 → L1**。先定主角，配角围绕主角设计。

## Step 1: 确定层级

对照上述层级表，确认角色层级。L4 走完整流程（Step 2-9 全部执行）。L3/L2/L1 按层级跳过非必填步骤。

## Step 2: 基础信息

全层级必填。姓名、年龄、外貌（≥1个记忆点，L4≥3个）、职业/身份、种族、出生背景、教育/经历。

**Lajos Egri 三维角色**（L4 必填，L3 选填，L2/L1 跳过）：

| 维度 | 包含内容 |
|------|---------|
| 生理维度 | 性别、年龄、身高、体重、健康状况、外貌、体态、缺陷/疤痕/特征 |
| 社会维度 | 阶层、收入、职业、家庭、教育、宗教、政治倾向、爱好、嗜好 |
| 心理维度 | 性格、气质、世界观、雄心、挫折、欲望、恐惧、复杂/互补、IQ/EQ |

命名遵守项目 `rules.md` 的命名规则。

---

## Step 3: 性格内核

### L4 主角级：完整 Wound → Lie → Want → Need

> 方法论见「三、方法论 §1 角色弧线设计」。

**核心公式**：

```
Wound（伤痛）→ 形成 Lie（谎言信念）
                    ↓
             角色用 Lie 看世界
                    ↓
             催生 Want（表层目标，角色知道）
                    ↓
             真正的 Need（深层需求，角色不知道，故事教他）
                    ↓
             故事结束：是否突破 Lie，接受 Need？
```

**因果链自检**：Wound 能解释 Lie 吗？Lie 能推导出 Want 吗？Want 和 Need 形成张力吗？三个都是"是"→ 通过。

**三词定义法**：用三个矛盾形容词。禁止同义堆砌。
```
✓ "聪明 + 社恐 + 嘴硬心软"（三个不同维度，有冲突）
✗ "聪明 + 机智 + 敏锐"（同一个意思说三遍）
```

填满：Want / 核心恐惧 / 致命缺陷 / Lie / Truth / 对外面具 / 真实自我。

### L3 完整性：简版

必填：三词定义 + Want（一句） + 动机简述（从什么出发追求什么，替代完整 Wound/Lie）。

### L2 有趣性：极简

必填：三词定义（三词即可，不展开）。

### L1 功能性：跳过。

---

## Step 4: 弧线设计

> 方法论见「三、方法论 §1 角色弧线设计」。

### L4 主角级：完整弧线

选择弧线类型 + 填写 5 节点 + 弧线 7 问检验。

五种弧线类型（详见方法论 §1.2-1.3）：

| 类型 | 轨迹 | 适用 |
|------|------|------|
| **正向弧线** | 信Lie → 被挑战 → 抵抗 → 面对 → 接受Truth → 改变 | 成长型主角 |
| **负向·堕落** | 信Truth → 受诱惑 → 接受Lie → 抛弃Truth → 堕落 | 堕落英雄 |
| **负向·加倍** | 信Lie → 被挑战 → 拒改 → 加倍Lie → 毁灭 | 偏执反派 |
| **负向·幻灭** | 信Lie → 看到Truth → 拒绝接受 → 崩塌 → 绝望 | 虚无主角 |
| **平坦弧线** | 已知Truth → 改变周围人 → 世界接受Truth | 传奇英雄/系列核心 |

五节点：起点 / 催化事件 / 中点觉醒 / 最低谷 / 终点。

弧线 7 问检验（详见方法论 §1.4）。

### L3 完整性：简版弧线

起点 + 催化 + 终点（三节点）。

### L2 / L1：跳过。

## Step 5: 声线卡

> 方法论见「三、方法论 §2 角色辨识度设计」。

**核心标准：遮住名字，只看对白，能认出谁在说话。**

### L4 主角级：声线卡（≥5 维，必要时可扩展）

| 维度 | 设计方法 |
|------|---------|
| 高频词/口头禅 | 2-3个专属词 |
| 句式偏好 | 长分析/短命令/反问/陈述 |
| 比喻习惯 | 科学类比/文学引用/日常俗语 |
| 情绪表达 | 外放/内敛/讽刺/温柔 |
| 禁忌词 | 绝不会说的话 |
| 称呼习惯 | 你/您/直呼其名/绰号 |
| 信息密度 | 废话多/惜字如金 |

### L3 完整性：至少 4 项

高频词 + 句式 + 情绪表达 + 禁忌词。

### L2 有趣性：至少 3 项

高频词 + 句式 + 情绪表达。

### L1 功能性：跳过。

## Step 6: 外在标记

> 方法论见「三、方法论 §2 角色辨识度设计」。

每个重要角色至少有 **1 个视觉标记 + 1 个行为标记**：
- **视觉标记**：疤痕、发色、穿着风格、标志性配饰、身高体态
- **行为标记**：习惯动作、独特姿势、重复行为、口头禅

L4：≥2个视觉 + ≥2个行为。L3：≥1视觉 + ≥1行为。L2：≥1视觉 + ≥1行为。L1：≥1个记忆点。

**单维度禁令**：禁止单一标签角色。
```
❌ 仅"高冷霸道总裁"
✅ 高冷霸道总裁 + 偷偷写诗 + 怕老鼠 + 收藏奇怪手办
```

## Step 7: 关系网

> 方法论见「三、方法论 §4 关系图谱设计」。

L4/L3 必填。标注：关系类型 + 温度（1-10）+ 互动模式 + 冲突点 + 演变方向 + 信息差（A知道B不知道的事）。
L2：只标与主角的关系。L1：跳过。

## Step 8: 反派专项

> 方法论见「三、方法论 §3 反派设计」。

仅当角色是**主要反派**（L3+且是核心冲突的对抗力量）时执行。

好反派的 5 条标准：他认为自己是对的、动机可被理解、构成真正威胁、与主角是镜像、在某个时刻让读者动摇。详见方法论 §3.1。

反派动机光谱（7 种类型）：理想型、创伤型、贪欲型、哲学型、镜像型、系统型、自然型。详见方法论 §3.2。

镜像关系设计：最强反派与主角共享同一个 Wound，选择了 Lie。详见方法论 §3.3。

反派检测题（4 问）。详见方法论 §3.4。

## 三、方法论

> 以下方法论照搬自角色设计框架。操作流程中每个步骤需参考的方法论标注在步骤标题下（「方法论见 §X」）。

---

## §1 角色弧线设计（K.M. Weiland）

> 对应操作流程：Step 3（性格内核）、Step 4（弧线设计）

### 1.1 核心公式：The Lie + Wound + Want + Need

```
Wound（伤痛）→ 形成 Lie（谎言信念）
                    ↓
The Lie → 角色 → Want（欲望，表层目标）
                    ↓
                Need（需求，深层真理）
                    ↓
                故事结束：是否突破 Lie 接受 Need？
```

### 1.2 正向弧线（Positive Arc）— 最常见

```
相信谎言 → 受到挑战 → 抵抗改变 → 被迫面对 → 接受真相 → 改变行为
```
- **起点**：相信 The Lie
- **催化**：事件挑战 The Lie
- **抵抗**：用 Lie 应对失败
- **顿悟**：看到 The Truth
- **改变**：接受 Need，放下 Want

**示例**：
- 自卑的人学会相信自己（Lie: "我不配" → Truth: "我值得"）
- 复仇者放下仇恨（Lie: "复仇能让我解脱" → Truth: "宽恕才是解脱"）

### 1.3 负向弧线（Negative Arc）— 悲剧/反派

**A. 堕落型**：好人走向黑暗
```
相信真相 → 受到诱惑 → 接受谎言 → 抛弃真相 → 堕落
```

**B. 加倍型**：执念越来越深
```
相信谎言 → 受到挑战 → 拒绝改变 → 加倍投入谎言 → 毁灭
```

**C. 幻灭型**：真相过于残酷
```
相信谎言 → 看到真相 → 拒绝接受 → 自我崩塌 → 绝望
```

**示例**：好人因为执念变成反派、英雄成为他曾经讨厌的样子

### 1.4 平坦弧线（Flat Arc）— 传奇英雄型

```
知道真相 → 进入不信真相的世界 → 通过行动改变周围人 → 世界接受真相
```
- 主角不变，世界变
- 主角是"真理的载体"
- 适合系列作品的核心英雄

**示例**：阿甘、绿巨人浩克、佐罗、捍卫战士

### 1.5 弧线检验清单

- [ ] The Lie 在第1幕清晰展示（通过行为不通过台词）
- [ ] Wound 在故事中至少暗示一次（不必明说）
- [ ] Want 是表层目标，与 Need 形成张力
- [ ] 中点：主角第一次"瞥见"真相
- [ ] 暗夜灵魂：主角最深的怀疑/恐惧
- [ ] 第3幕：主角主动选择放下 Lie
- [ ] 结局：行为证明 Truth 已被接受（不通过台词，通过行动）

## §2 角色辨识度设计

> 对应操作流程：Step 5（声线卡）、Step 6（外在标记）

### 2.1 对话辨识度检测

**标准**：遮住角色名，只看对话，能不能辨认出是谁在说话？

| 维度 | 设计方法 |
|------|---------|
| 用词习惯 | 每个角色有 2-3 个专属高频词/口癖 |
| 句式结构 | 有人爱用长句分析，有人说话断断续续 |
| 信息密度 | 有人废话多，有人惜字如金 |
| 潜台词程度 | 有人直接说，有人永远绕圈 |
| 情绪表达 | 有人外放，有人压抑 |
| 文化层次 | 用词水平区分（书面/口语/俚语/方言） |
| 礼貌度 | 称呼习惯（你/您/小+名字/直呼其名） |

### 2.2 声线卡示例

**A 角色**：理性程序员，社恐
- 高频词：理论上、概率、按道理
- 句式：分点陈述、长句包含定语从句
- 比喻：技术类比（"像 bug 一样"、"内存溢出"）
- 禁忌：不说"我爱你"，会说"我系统已为你保留专属端口"

**B 角色**：暴脾气退伍兵
- 高频词：他妈的、爷、操、滚
- 句式：超短句、命令式、感叹句多
- 比喻：军事/暴力类比（"像挨了一枪"、"火力压制"）
- 禁忌：从不解释自己，从不示弱

**C 角色**：温婉江南女子
- 高频词：嗯、罢了、挺好的
- 句式：完整长句但语气柔和、多用问句
- 比喻：自然/古典类比（"像春雨"、"像旧瓷器"）
- 禁忌：从不直接说"不"，会用迂回方式

### 2.3 外在标记设计

每个重要角色至少有 **1 个视觉标记 + 1 个行为标记**：
- **视觉标记**：疤痕、发色、穿着风格、标志性配饰、身高体态
- **行为标记**：习惯动作、独特姿势、重复行为、口头禅

### 2.4 单维度禁令

**禁止单一标签角色**：
- ❌ 仅"高冷霸道总裁"
- ✅ 高冷霸道总裁 + 偷偷写诗 + 怕老鼠 + 收藏奇怪手办

## §3 反派设计

> 对应操作流程：Step 8（反派专项）

### 3.1 好反派的标准

- ✅ 他认为自己是对的（从他的视角看逻辑自洽）
- ✅ 他有可以被理解（甚至同情）的动机
- ✅ 他的能力足以构成真正威胁
- ✅ 他和主角在某个层面是"镜像"
- ✅ 他在某个时刻让读者动摇（"也许他有道理？"）

### 3.2 反派动机光谱

| 类型 | 动机 | 示例 |
|------|------|------|
| 理想型 | 为"更好的世界"不择手段 | 灭霸（平衡宇宙） |
| 创伤型 | 过去的伤害导致极端行为 | 大多数复仇型反派 |
| 贪欲型 | 对权力/金钱/控制的渴望 | 经典权谋反派 |
| 哲学型 | 与主角代表不同价值观 | 小丑 vs 蝙蝠侠 |
| 镜像型 | "如果主角走了另一条路" | 主角的暗面映射 |
| 系统型 | 反派是体制本身，没有具体人 | 《1984》大哥、卡夫卡式 |
| 自然型 | 自然灾害/疾病/末日 | 《老人与海》的鲨鱼、瘟疫 |

### 3.3 反派与主角的镜像关系

最有力的反派与主角共享同一个 Wound，但选择不同：

| 主角 | 反派 |
|------|------|
| 同样的童年伤痛 | 同样的童年伤痛 |
| 选择正面应对 | 选择拥抱黑暗 |
| The Truth | The Lie |

**示例**：
- 蝙蝠侠 vs 小丑：都因创伤变得不正常，蝙蝠侠选择"秩序"，小丑选择"混乱"
- 哈利波特 vs 伏地魔：都是孤儿+混血+蛇佬腔，哈利选择爱，伏地魔选择恐惧

### 3.4 反派检测题

- 反派从他自己的视角看，他的行为合理吗？
- 反派有没有让读者短暂同情/理解的瞬间？
- 把反派的故事单独写一本书，能不能成立？
- 反派和主角能不能"互换"？（如果不能，可能层次差太多）

## §4 关系图谱设计

> 对应操作流程：Step 7（关系网）

### 4.1 核心关系类型

| 关系 | 叙事功能 | 冲突来源 |
|------|---------|---------|
| 师徒 | 成长线 + 传承主题 | 超越/背叛/失去 |
| 对手 | 压力源 + 成长催化 | 竞争/理念冲突 |
| 搭档 | 互补 + 日常趣味 | 分歧/信任危机 |
| 感情 | 情感线 + 软肋 | 误解/选择/牺牲 |
| 仇敌 | 外部压力 + 过去纠葛 | 复仇/原谅 |
| 亲情 | 根源 + 内心矛盾 | 期望/反叛/和解 |
| 友情 | 支持 + 底色 | 价值观/路线分歧 |

### 4.2 关系动态化原则

- 关系不是静态的 — 每个重大事件后关系应该有变化
- 用"秘密"驱动关系变化 — A 知道 B 不知道的事 → 张力
- 三角关系制造冲突 — 不只是感情三角，任何三人利益冲突都有效

### 4.3 关系矩阵（多角色作品必备）

| | 角色A | 角色B | 角色C | 角色D |
|---|---|---|---|---|
| 角色A | — | 兄弟/嫉妒 | 师父/敬畏 | 仇人/仇恨 |
| 角色B | 兄弟/嫉妒 | — | 暧昧/未明 | 陌生 |
| 角色C | 师父/慈爱 | 暧昧/克制 | — | 敌对/警惕 |
| 角色D | 仇人/利用 | 不认识 | 敌对/想杀 | — |

**注意**：A 对 B 和 B 对 A **不一定相同**（例如：A 嫉妒 B，但 B 视 A 为亲兄弟）

### 4.4 关系演变追踪表

每章末记录：

```markdown
## 第N章 关系变化

| 角色对 | 之前 | 现在 | 触发事件 |
|--------|------|------|---------|
| A→B | 兄弟 | 仇人 | 第N章 B 杀了 A 的师父 |
| C→D | 警惕 | 敌对 | 第N章 D 暴露身份 |
```

## §5 配角设计原则

> 对应操作流程：Step 1（确定层级）、Step 2-7（L2/L3 角色的设计）

### 5.1 配角的三个功能

1. **镜子功能** — 映照主角的某个侧面（正面或反面）
2. **催化功能** — 推动/阻碍主角的改变
3. **世界功能** — 展示世界观的某个切面

### 5.2 配角设计的"3要1不要"原则

**3要**：
1. **要有自己的目标**（哪怕和主线无关）
2. **要有自己的弱点**（让读者共情）
3. **要有自己的"在场理由"**（不是为主角服务）

**1不要**：
- 不要为了"金句""冷场救场""信息传递"而存在 → 工具人感

### 5.3 4 大配角原型

| 原型 | 功能 | 示例 |
|------|------|------|
| 导师（Mentor） | 引导主角成长 | 邓布利多、奎刚 |
| 阴影（Shadow） | 主角的反面 | 反派/对手/暗黑面 |
| 守门人（Threshold Guardian） | 阻止主角进入新世界 | 第一个 Boss、严父 |
| 变形者（Shapeshifter） | 立场不明确，制造怀疑 | 双面间谍、亦正亦邪 |

## §6 群像作品的角色管理

> 对应操作流程：全局（特别是多角色作品的 POV 和出场管理）

### 6.1 角色权重分层

| 层级 | 数量 | 笔墨占比 | 设计深度 |
|------|------|---------|---------|
| 主角（POV） | 1-3 | 60-80% | 完整三维 + 弧线 |
| 重要配角 | 5-10 | 15-30% | 完整动机 + 自己的小弧线 |
| 关键路人 | 10-30 | 5-10% | 1-2 个特征 + 功能 |
| 背景角色 | 不限 | <5% | 仅名字 + 一句话 |

### 6.2 POV（视角）切换规则

- 一个场景一个 POV — 不要在一个场景内换视角
- 每章固定一个 POV — 给读者明确的"代入对象"
- POV 角色必须**有信息差** — 不同 POV 知道不同的事
- POV 切换要有**节奏感** — 不要每章都换，也不要 5 章不换

### 6.3 群像作品的"角色出场顺序"

第 1-3 章只能出现 ≤5 个角色（读者大脑容量有限）

之后每 2-3 章引入 1 个新重要角色（带着记忆点出场）

## §7 角色一致性检查（防"OOC"）

> 适用：全周期。初稿写作（05）和修订审稿（06）阶段的核心检查工具。

### 7.1 OOC（Out Of Character）的定义

角色做出违背其人设的行为，没有合理铺垫。

### 7.2 一致性检查清单

- [ ] 这个角色在压力下的反应，符合他的"压力反应"设定吗？
- [ ] 这段对话的用词，符合他的"声线卡"吗？
- [ ] 他做这个决定的时候，有没有内心挣扎？（没有 = 太顺=不真实）
- [ ] 这个行为与他的核心欲望/恐惧一致吗？
- [ ] 他知道这件事吗？（信息一致性，避免全知）
- [ ] 他现在的能力等级与之前一致吗？（修真/玄幻题材）

### 7.3 角色"突变"的合法路径

如果角色行为发生重大变化，必须经过：

1. **触发事件**（重大刺激）
2. **挣扎过程**（内心冲突外化）
3. **关键选择**（有意识的决定）
4. **行为变化**（之后所有行为体现新状态）

❌ 突然变化（无铺垫）= OOC = 灾难

## 常见错误

1. **L1 角色误填全卡。** L1 功能性角色只需基础和登场记录，填全卡是浪费。层级判定后再操作。
2. **三词堆砌同义词。** "聪明+机智+敏锐"是同一个意思说三遍，无辨识度。三个词必须来自不同维度且有内在冲突。
3. **Wound→Lie 因果不通。** 伤痛解释不了谎言信念 → 弧线逻辑崩盘。三步自检：Wound 能解释 Lie 吗？Lie 能推导 Want 吗？Want 和 Need 形成张力吗？
4. **声线卡写了等于没写。** "句式：正常说话"不叫声线卡。遮住名字读对话，分不出谁在说话 → 重做。
5. **反派动机不足。** 反派只是"坏"没有原因 → 扁平。好反派必须：他认为自己是对的、有可理解的动机、与主角是镜像。
6. **角色关系静态。** 关系只写"朋友"不写温度、冲突点、演变方向 → 关系没有叙事动力。
